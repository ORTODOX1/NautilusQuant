## Дай отчёт по 4 слоям

### Слой 1 — Архитектура (как у `architecture.md`)
- Топ-3 фундаментальных ошибки
- Топ-3 удачных решения
- Punch list изменений с файл:строка

### Слой 2 — Корректность (как у `correctness.md`)
- Список багов: severity / file:line / описание / репродуктор / фикс
- Что обязательно добавить в тесты

### Слой 3 — Performance (как у `performance.md`)
- Топ-3 хотспота с patch-style diff
- Оценка ускорения после фикса
- Что не оптимизировать

### Слой 4 — Roadmap (как у `roadmap.md`)
- 6 этапов: E1 RTL → E2 FPGA → E3 HF → E4 vLLM → E5 ASIC → E6 board
- Цена / время / риски / нужные специалисты
- Альтернативы (Tenstorrent, Groq Compiler, и т.д.)

## Формат

Один большой markdown-документ. Раздели заголовками `## Слой 1`, `## Слой 2`, и т.д. Всё конкретно — никаких «в целом», только: «измени X на Y», «добавь файл Z», «потрать $N на этапе E2», и пр.

Длина — без ограничений (хочу вернуть инвестицию в токены).
